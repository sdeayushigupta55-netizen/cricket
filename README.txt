Googly - cricket prediction demo (demo coins only)

HOW TO RUN
1. Unzip this folder.
2. Double-click index.html (opens in any modern browser). No install needed.
3. Log in with the demo account (username: demo, password: demo) or sign up.

NOTES
- Single file: HTML + CSS + JavaScript in index.html.
- Accounts and progress are saved in the browser (localStorage) only.
  This is a front-end demo, not real security. Do not reuse real passwords.
- The match is a built-in simulator. For real matches you need a backend
  that polls a licensed cricket data API and serves results to this page.
- Coins have no cash value. There are no deposits or withdrawals.
- Upcoming fixtures are a fixed list (checked 18 Nov 2026) in the UP array.
